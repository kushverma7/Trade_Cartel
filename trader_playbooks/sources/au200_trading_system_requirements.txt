DE v4 TREND Signal Logic
Hard gate (ALL 3 must pass for a TREND signal):
 LONG gate: SuperTrend bullish + price above EMA200 + EMA50 rising
 SHORT gate: SuperTrend bearish + price below EMA200 + EMA50 falling
Confluence scoring (need min 3 of 5):
 SuperTrend bullish/bearish
 AlphaTrend continuously bullish/bearish (AT > AT[2] > AT[4])
 Price above/below EMA200
 RSI in bull zone (45-70) or bear zone (30-55)
 MACD line above/below signal line
TREND BUY fires when: hard gate passes + score ≥ 3
TREND SELL fires when: hard gate passes + score ≥ 3
The Pine code is already in research/DE_v4_V2.pine. Any strategy should import or replicate this logic
exactly.
3. OPENING TRADE SYSTEM
Source file: research/open_trade.pine (indicator) and research/opening_system_report.pdf
Entry Rules
1. Time: 9:50 AM + 9:55 AM + 10:00 AM AEST — all three bars
- Timezone: "Australia/Sydney" (handles AEST UTC+10 and AEDT UTC+11 automatically)
- Do NOT use hardcoded "UTC+10" — this fires 1 hour early Oct–Apr during daylight saving

5. Max trades: 1 trade per session day. Once entered, no more entries until next day.
Exit Rules

 No trailing stop in this system. Fixed TP and SL only.

7. WHAT WAS WRONG WITH EVERY VERSION BUILT
1. UT Bot — completely wrong indicator system. DE v4 is the real system.
2. UTC+10 hardcoded — fires 1 hour early Oct–Apr. Must use Australia/Sydney.
3. Flip SL signs inverted in ema_hybrid_v2 — caused 5,000+ cascading trades.
4. process_orders_on_close=true — entry and exit processed on same bar close. Must be false so entry
fills at next bar open per PDF rule.
5. Approximate signal — EMA200+RSI only is not DE v4. Must use the real engine.
6. 1-month backtest — not representative. Must use "All" (full history 2016–2026).
