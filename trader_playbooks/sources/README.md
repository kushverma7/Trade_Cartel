# Source materials — permanent archive

Every original PDF, text extraction, and raw pasted transcript this
project's playbooks were built from, copied here so it survives beyond
any single session's upload storage (which is ephemeral). Nothing in
this directory should be deleted — per the project's standing "never
discard" rule, low-value or unused sources stay archived and clearly
marked, same as everywhere else in this repo.
